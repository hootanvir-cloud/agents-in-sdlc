Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software con escenarios realistas, una aplicación completa y un backlog compartido. Trabajarás de forma iterativa para planificar cambios, crear código, probar su comportamiento, revisar solicitudes de incorporación de cambios y gestionar el trabajo con agentes.

## Escenario

Eres un nuevo desarrollador en Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con temática de desarrollo. El backlog de tu equipo ya está registrado como incidencias de GitHub, listas para que las elijas. Incluye funcionalidades como el filtrado y la paginación, además de mejoras de calidad relacionadas con la accesibilidad y los estándares de programación.

## Elige tu entorno

GitHub Copilot está disponible dondequiera que trabajes. Elige el entorno que mejor se adapte a tu forma de desarrollar. Cada taller comienza con su propia configuración y utiliza el escenario compartido de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente con agentes en el terminal. Trabaja con los modos Plan y Autopilot, instrucciones, habilidades, agentes personalizados, Playwright MCP, Agent Merge y prácticos comandos de barra.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agente en paralelo, cambia de modo de sesión, colabora en lienzos y gestiona incidencias y solicitudes de incorporación de cambios de GitHub desde la aplicación de escritorio.

### [Agente de GitHub Copilot en la nube][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa el progreso y revisa las solicitudes de incorporación de cambios que abre.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con Copilot Chat en modo agente, servidores MCP y agentes personalizados sin salir del editor.
